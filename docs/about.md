# About MARGE

**MARGE** is born in 2025 as a school project of students from the french school of engineering *IMT Mines Ales*. It is an acronym for **M**inimalistic **A**ccessible **R**ISC-V **G**aming **E**nvironment.

<u>The project is composed of :</u>

- A fantasy console named *ROSE*.
- An online IDE. 
- A store and forum.

We wanted to create a **simple** yet **effective** environment on wich one could program games for our console, share them and play games from other people, whether he's a beginner or a more skilled developper.
To this end, we provide a C library and a no-code scripting language to develop games
